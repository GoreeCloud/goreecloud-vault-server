# GoreeCloud Vault Server Branding

All branding authority belongs to `GoreeCloud/goreecloud-branding-assets`.

Approved GoreeCloud Vault product artwork is stored at `products/vault/app-icon.svg`. Vault Server may retain required synchronized derivatives for packaging, deployment, documentation, or administrative surfaces, but it must not establish a separate branding authority. Any server-specific artwork must be created and approved in the unified branding repository first.

Branding does not establish credential-security, runtime, deployment, or release claims.
